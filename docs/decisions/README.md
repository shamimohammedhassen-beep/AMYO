# Decision handling (public index only)

The AMYO project must distinguish:
- **Source-reported:** original document statements (may need verification).
- **Owner-approved:** dated, explicit project owner decisions.
- **Proposed:** recommendations requiring a recorded ruling.
- **Verified external fact:** evidence with publisher/source/date/scope.
- **Open:** missing authority, validation or detailed design.

**Current approved infrastructure-only choices:** common GitHub source repository; separated Cloudflare frontend projects; existing single Supabase project; independent frontend builds.

**Not approved by these choices:** corporate authority matrix, individual approver identities, production accounting rules, external banking integrations, private document sharing, ERP launch or any fiscal/legal determination.

Do not publish internal decision packages to this repository while it remains public. Store sensitive corporate rulings, person names, signatures, roles, banking material and supporting evidence in an owner-approved restricted system. This directory will only contain a redacted index.
